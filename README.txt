BRUTO — sitio para Neocities

1. Subí todos estos archivos a tu sitio de Neocities.
2. Reemplazá "fondo.jpg" por la foto que quieras usar como fondo repetido.
3. index.html es la página principal.
4. Las páginas track-1.html a track-9.html contienen las letras proporcionadas.

IMPORTANTE SOBRE LAS FOTOS:
Neocities, por sí solo, no ofrece un formulario HTML que permita a visitantes
subir archivos al servidor y compartirlos entre todos. La versión incluida
guarda las imágenes en localStorage del navegador de cada visitante: sirven
para que la persona vea sus propias fotos en ese navegador, pero no son
públicas para los demás. Para una galería pública compartida hay que conectar
un servicio externo de almacenamiento/backend.
